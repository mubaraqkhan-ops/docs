## Prerequisites

To interact with the Mindcare Oracle, your agent needs:
1. **Python 3.10+**
2. **x402 SDK** installed via pip (`pip install x402 httpx eth-account`).
3. A **Base Network** wallet funded with at least **$0.05 USDC** and a fraction of ETH for gas.

---

## The Integration Script

The Oracle operates strictly on the `x402` Machine-to-Machine payment protocol. When your agent fires a standard `POST` request, the Oracle will intercept it and return a `402 Payment Required` header containing a Base network invoice.

Here is the exact Python implementation to automatically parse the invoice, sign the transaction, and decrypt the premium payload.

```python
import json
import httpx
from eth_account import Account
from x402.client import HTTPFacilitatorClient, FacilitatorConfig
from x402.http import x402HttpClient

# 1. Initialize your Agent's Wallet
bot_pk = "YOUR_PRIVATE_KEY_HERE"
bot_account = Account.from_key(bot_pk)

# 2. Configure the x402 Client
facilitator = HTTPFacilitatorClient(
    FacilitatorConfig(url="https://api.cdp.coinbase.com/platform/v2/x402/")
)
client = x402HttpClient(signer=bot_pk, facilitator=facilitator)

# 3. Fire the Request (Handles the 402 Handshake Automatically)
try:
    response = client.post(
        "https://api.mindcare.agency/analyze",
        json={"pair": "BTCUSDT"},
        timeout=15.0
    )
    
    if response.status_code == 200:
        print("Payment Successful. Premium Payload:")
        print(json.dumps(response.json(), indent=2))

except Exception as e:
    print(f"Handshake Error: {str(e)}")
```
