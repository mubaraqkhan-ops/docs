## Authentication

This endpoint uses the `x402` machine-to-machine protocol. **No traditional API keys are required.** Every initial request will return a `402 Payment Required` status. Your client must parse the invoice in the headers, execute the $0.05 payment on the Base network, and automatically resubmit the request with the transaction receipt.

---

<ParamField body="pair" type="string" required>
  The trading pair you want the Oracle to analyze. Must be a valid perpetual futures ticker supported by both Binance and Bybit. 
  
  Example: BTCUSDT or ETHUSDT
</ParamField>

---
